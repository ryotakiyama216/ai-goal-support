## 作りたいもの: タスク詳細画面

### 目的

リストでは見えない文脈を、1 タスクに集中して見せる。  
Goals 配下のタスクも同じ詳細を使う。

### 表示したい情報

1. **どの目標のタスクか** … `goalId` → Goal タイトル
2. **親タスクは何か** … `parentTaskId` → 親のタイトル（リンク）
3. **兄弟タスク** … 同じ `parentTaskId` の一覧
4. **同じ大きさのタスクが何件あるか** … 親の下で、同サイズの兄弟数（要: サイズ属性の設計）
5. **中身** … タイトル + note（本文）+ 期限・優先度・Today/Inbox 状態

### タスク単位 AI

- グローバルチャットではなく、**そのタスクの文脈**で最適な回答
- 渡すコンテキスト例: 目標、親、兄弟、note、期限、ユーザープロフィール
- 用途例: 次の 1 アクション、分解案、Today に入れるべきか
- UX: チャットアプリ化は避け、詳細内の「静かな AI」ブロック程度

### 画面イメージ（ルート案）

```
/tasks/[id]
├── ヘッダー（タイトル、完了、Today/Inbox）
├── 文脈（目標 / 親 / 兄弟・同サイズ件数）
├── 本文（note 編集）
└── AI ブロック（タスク文脈付き）
```

### 既存コードで使えるもの

- `types/index.ts` … `goalId`, `parentTaskId`
- `lib/taskTree.ts` … ツリー・グループ
- `store/useTaskStore.ts` … `updateTask`, 目標・タスク取得

### これから足すもの
